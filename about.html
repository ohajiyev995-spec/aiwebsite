About Titans Atlas

Titans Atlas is a non-commercial fan project that highlights the lore of the Nine Titans through accessible, responsive web design.

Project overview

Built with semantic HTML, modular CSS, and vanilla JavaScript, Titans Atlas keeps dependencies light so that it can deploy smoothly on GitHub Pages or Netlify. Content is sourced from a concise JSON dataset, which powers interactive tooltips and modals on the Titans page.

How it’s built

  • Vanilla HTML, CSS custom properties, and modern layout primitives (flexbox and grid)
  • Progressive enhancement techniques for interactivity with fetch and browser APIs
  • Dark/dim mode toggle that respects system preferences and persists via localStorage
  • Keyboard accessibility features including focus outlines, modal focus trapping, and shortcut help

Accessibility notes

Navigation, buttons, filters, and Titan cards are keyboard reachable and provide visible focus states. The tooltip uses ARIA semantics and live regions for assistive technology. Reduced-motion preferences disable non-essential transitions, and color contrast adheres to WCAG AA targets.
