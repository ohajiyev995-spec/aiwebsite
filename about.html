About Titans Compendium

This spoiler-light fan reference charts every Nine Titan alongside all known inheritors. Each profile is data-driven, fully client-side, and keeps focus on accessibility so anyone can explore the lineage comfortably.

How it’s built

  • Vanilla HTML, CSS, and JavaScript—no frameworks or build steps.
  • Content sourced from data/titans.json, fetched at runtime with a fallback dataset for file:// browsing.
  • Original abstract silhouettes rendered with currentColor so themes remain consistent.

Accessibility highlights

  • Keyboard navigation supports filter controls, cards, and modal interactions with visible focus rings.
  • prefers-reduced-motion respected to tone down hover elevation and transitions.
  • Dialogs trap focus, close via ESC/backdrop, and restore focus to the triggering element.
