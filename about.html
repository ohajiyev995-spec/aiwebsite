About this project

A lean, fan-made compendium focused on legitimacy, accessibility, and resilience.

What it is

The Titans Compendium is an educational, spoiler-aware reference for the Nine Titans and every inheritor. It balances lore-friendly summaries with spoiler-light notes so newer fans can explore with confidence.

How it is built

This site is written in vanilla HTML, CSS, and JavaScript. Data lives in a JSON file, and every page degrades gracefully under file:// browsing thanks to inline fallbacks that mirror hosted data.

Accessibility commitments

  • Keyboard-first navigation with clear focus states and modality controls.
  • Reduced-motion support that prefers gentle transitions for sensitive users.
  • Semantic markup with accessible names, labels, and live regions.

Disclaimer

Attack on Titan and related names belong to their respective rights holders. All silhouettes were created specifically for this project as abstract art and are intended solely for non-commercial, educational use.
