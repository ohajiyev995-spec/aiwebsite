About this fan project

Attack Titan Lineage is now a broader, spoiler-light Titans Compendium that highlights both the Attack Titan inheritors and a curated overview of the Nine Titans alongside notable pure/abnormal sightings. Content stays high-level to preserve key story beats.

How it’s built

  • Static vanilla HTML, CSS, and JavaScript—no frameworks or build tooling.
  • Structured data stored in data/attack_titans.json, with a JavaScript fallback so pages still render if the JSON can’t be fetched.
  • Modular scripts: scripts/main.js handles theme toggling, shared helpers, and featured sections; scripts/inheritors.js powers the lineage roster; scripts/titans.js drives the titan compendium grid and modal.

Accessibility notes

  • Keyboard-focused navigation with prominent outlines using the accent color and visible focus states across cards and controls.
  • Reduced motion settings respected—hover lifts and transitions tone down when prefers-reduced-motion is enabled.
  • Modal dialogs on both lineage and titan pages trap focus, support Escape/backdrop dismissal, and restore focus to the triggering control.
